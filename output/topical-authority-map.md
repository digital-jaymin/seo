## How to Read This Map

- **Authority Score** `/10` — current topical authority based on blog coverage, pillar/spoke structure, and cluster depth
- **Coverage** — published blog count vs gap count
- **Pillar** — the one article that holds the cluster together (links to all spokes)
- **Spoke** — supporting articles that link back to the pillar and to collection pages
- **Collection Owner** — collection page that owns the transactional keyword (blogs must NOT compete here)
- **Gap Priority** — HIGH = write now / MEDIUM = write next / LOW = write later
